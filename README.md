# Mallu.gg2 🎮

A static meme-based project built with HTML. This repository serves as a birthday trolls containing multimedia elements like audio and images. 

## 🚀 Features

* **Multimedia Integration**: Seamlessly incorporates audio and image assets.
* **Lightweight**: Pure HTML-based structure for fast loading and high performance.
* **Simple Architecture**: Easy to understand and modify, perfect for static hosting.

## 🛠️ Tech Stack

* **HTML5**: Core structure and page layout (100% of the codebase).

## 📁 Directory Structure

```text
Mallu.gg2/
├── audio/          # Contains all sound and audio files
├── images/         # Contains all graphics, icons, and image assets
└── index.html      # Main entry point of the application
```

## 💻 How to Run (Local Development)

Since this is a static HTML project, you don't need any complex backend servers or package managers to run it.

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/ZebbyAnnan-pixel/Mallu.gg2.git](https://github.com/ZebbyAnnan-pixel/Mallu.gg2.git)
   ```
2. **Navigate to the directory:**
   ```bash
   cd Mallu.gg2
   ```
3. **Open the project:**
   Simply double-click `index.html` to open it in your default web browser, or use a tool like Live Server in VS Code for hot-reloading.
